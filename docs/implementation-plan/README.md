## Admin Legal Knowledge Base

LEXIS includes an Admin Panel for managing legal documents used by the Rights Agent's RAG pipeline. Authorized administrators can upload PDF, DOCX, and JSON files, inspect extracted content, manage document activation, and make approved legal knowledge available for retrieval.

See the [Admin Legal Knowledge Base documentation](docs/ADMIN_LEGAL_KNOWLEDGE_BASE.md) for the architecture, API endpoints, setup instructions, and verification checklist.
